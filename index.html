1เริ่มต้นใช้งาน

ระบบนี้ใช้ดู เซ็นอนุมัติ และ Reject เอกสาร PDF ของแต่ละแผนกผ่านเว็บเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรม

  1. เปิดเว็บ http://idf-docker.index-idf.com:8080 (ต้องใช้เครือข่ายของบริษัท)
  2. เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านที่ผู้ดูแลระบบสร้างให้
  3. ใช้งานเสร็จ กด ออกจากระบบ ทุกครั้ง โดยเฉพาะเครื่องที่ใช้ร่วมกัน
เอกสารต้นทุนและข้อมูลการผลิตเป็นความลับ ห้ามแชร์รหัสผ่าน และห้ามส่งไฟล์ให้คนนอกบริษัท
  • แต่ละคนเห็นและเซ็นได้เฉพาะแผนกและขั้นตอนที่ได้รับสิทธิ์ ถ้าไม่เห็นแผนกหรือไม่มีปุ่มเซ็น ให้แจ้งผู้ดูแลระบบ
  • ทุกการเซ็น ยกเลิก Reject อัปโหลด และลบ ถูกบันทึกประวัติถาวร

4การเซ็นเอกสาร

  1. เปิดแผนก และโฟลเดอร์ย่อยที่มีเอกสาร
  2. คลิกไฟล์ ระบบจะแสดง PDF พร้อมแถบเซ็นเอกสาร
  3. ตรวจเอกสารให้ครบทุกหน้า การเซ็นคือการยืนยันว่าคุณตรวจแล้ว
  4. ดูกรอบเส้นประบนหน้าสุดท้าย ว่าตรงช่องเซ็นของคุณ (ดูภาพ)
  5. กด เซ็นเอกสาร ระบบใส่ลายเซ็นและวันที่ลงในช่อง และบันทึกผู้เซ็นกับเวลา

กรอบสีบอกอะไร

กรอบความหมายทำอย่างไร
สีน้ำเงินระบบเจอป้าย "ผู้จัดทำ / ผู้ทบทวน / ผู้อนุมัติ" ในเอกสาร และวางช่องให้เองเซ็นได้เลย
สีส้ม + แถบเตือนระบบหาช่องเซ็นอัตโนมัติไม่เจอ ใช้ตำแหน่งที่ตั้งไว้แทนตรวจว่ากรอบตรงช่องจริงก่อนเซ็น ถ้าไม่ตรงอย่าเซ็น แจ้งผู้ดูแลระบบ
  • ช่องเซ็นอยู่หน้าสุดท้ายของเอกสารเสมอ ไม่ว่าเอกสารมีกี่หน้า
  • ถ้าไม่ใช่คิวของคุณ (ขั้นก่อนหน้ายังไม่เซ็น) ปุ่มเซ็นจะกดไม่ได้ และระบบบอกเหตุผล
  • เซ็นที่รอบล่าสุดเท่านั้น อย่าเซ็นรอบเก่า

5เซ็นหลายไฟล์พร้อมกัน

ใช้เมื่อมีเอกสารแบบเดียวกันหลายใบที่ถึงคิวคุณ ไม่ต้องเปิดเซ็นทีละใบ

  1. ในรายการเอกสาร ติ๊กช่องหน้าไฟล์ที่ต้องการ (สูงสุด 20 ไฟล์ต่อครั้ง)
  2. กด เซ็นที่เลือก (N)
  3. ตรวจรายชื่อไฟล์ในหน้าต่างยืนยัน และเลือกรูปแบบลายเซ็นครั้งเดียว (ระบบจำรูปแบบที่คุณเลือกล่าสุดไว้ให้)
  4. กด ยืนยันเซ็น N ไฟล์ ระบบเซ็นทีละไฟล์ และแสดงผลรายไฟล์ สำเร็จ / ข้าม / ล้มเหลว
  5. ไฟล์ที่ล้มเหลว กด ลองใหม่เฉพาะที่ล้มเหลว
  • ติ๊กได้เฉพาะไฟล์ที่ถึงคิวคุณ เป็นรอบล่าสุด ไม่ถูก Reject และอยู่แผนกเดียวกัน
  • ไฟล์ที่ระบบหาช่องเซ็นอัตโนมัติไม่เจอจะถูกข้าม พร้อมข้อความ "หาช่องเซ็นไม่เจอ กรุณาเปิดเซ็นทีละไฟล์" ระบบจะไม่เซ็นแบบเดา
การเซ็นหลายไฟล์คือการเซ็นจริงทุกใบ ตรวจเอกสารให้ครบก่อนกดยืนยัน

6ดาวน์โหลด PDF

ดาวน์โหลดได้ทุกสถานะ ไฟล์ที่ได้มีลายเซ็นเท่าที่เซ็นไปแล้ว ไม่ว่าเซ็นกี่ช่อง

สถานะเอกสารไฟล์ที่ได้
ยังไม่เซ็นไฟล์ต้นฉบับ
กำลังเซ็นไฟล์ที่มีลายเซ็นเท่าที่เซ็นแล้ว
อนุมัติแล้วไฟล์ที่เซ็นครบทุกช่อง
ไฟล์ที่ดาวน์โหลดเป็นข้อมูลความลับ เก็บในเครื่องของบริษัทเท่านั้น

7ยกเลิกลายเซ็น

ถ้าเซ็นผิด ยกเลิกลายเซ็นของตัวเองได้จากแถบเซ็นของเอกสารนั้น เอกสารจะกลับไปรอเซ็นขั้นนั้นอีกครั้ง

  • ยกเลิกได้เฉพาะลายเซ็นของตัวเอง (หรือผู้ดูแลระบบทำแทน)
  • ไม่มีการลบประวัติ ระบบบันทึกว่ามีการยกเลิกและใครทำ
  • ถ้าเอกสารเซ็นครบแล้วแต่ต้องแก้ ให้ใช้ Reject แล้วรอรอบใหม่ (หัวข้อ 8)

8Revise และ Reject

Revise คือเอกสารรอบใหม่ที่แก้แล้ว Reject คือการปฏิเสธเอกสารที่ข้อมูลผิด

8.1 รอบแก้ไข (Revise)

  • ไฟล์ฉบับแรก (R0) ไม่มีส่วนท้าย รอบถัดไปต่อท้าย _R1, _R2 …
  • รายการหลักแสดงเฉพาะรอบล่าสุด กด รอบก่อนหน้า (n) เพื่อดูรอบเก่า
  • รอบใหม่ต้องเซ็นใหม่ทั้งหมด แม้รอบเก่าเคยอนุมัติแล้ว
  • รอบเก่าที่เคยอนุมัติติดป้าย "เคยอนุมัติ (ถูกแทนที่แล้ว)" ห้ามนำไปใช้

8.2 Reject เอกสาร

  1. เปิดเอกสารที่ข้อมูลผิด กด Reject เอกสาร ในแถบเซ็น (เห็นเฉพาะคนที่มีสิทธิ์ขั้นนั้น)
  2. กรอกเหตุผล 3–500 ตัวอักษร ให้ชัดว่าผิดตรงไหน
  3. ยืนยัน ระบบส่งอีเมลพร้อม PDF ถึงผู้ที่เซ็นขั้นก่อนหน้า
  4. เอกสารไปอยู่โฟลเดอร์ REJECT ของแผนกนั้น และเซ็นไม่ได้จนกว่าจะยกเลิก Reject

8.3 ยกเลิกการ Reject

ทำได้เฉพาะคนที่ Reject เอง หรือผู้ดูแลระบบ เปิดเอกสารในโฟลเดอร์ REJECT แล้วกด ยกเลิกการ Reject เอกสารจะกลับไปเซ็นได้ตามปกติ

8.4 ลำดับเหตุการณ์ทั่วไป

  1. ผู้เซ็นพบข้อมูลผิด → Reject พร้อมเหตุผล
  2. ผู้เซ็นขั้นก่อนหน้าได้อีเมลแจ้ง
  3. เจ้าของงานแก้ แล้วออกรอบใหม่ (จาก AX หรืออัปโหลดชื่อเดิมซ้ำ หัวข้อ 9)
  4. รอบใหม่เซ็นใหม่ตั้งแต่ขั้นแรก รอบที่ถูก Reject ยังเก็บไว้เป็นหลักฐาน

9อัปโหลดไฟล์

เอกสารต้นทุนส่วนใหญ่มาจาก AX อัตโนมัติ เอกสารอื่นอัปโหลดเองได้ (เฉพาะคนที่มีสิทธิ์)

  1. เลือก แผนก ปี เดือน และโฟลเดอร์ย่อยปลายทาง
  2. ลากไฟล์มาวาง หรือกด เลือกไฟล์ ได้หลายไฟล์พร้อมกัน
  3. กด อัปโหลด แล้วดูผลรายไฟล์ ไฟล์ที่ล้มเหลวกด ลองใหม่เฉพาะที่ล้มเหลว

อัปโหลดชื่อเดิมซ้ำ = Revise อัตโนมัติ

ถ้าแก้เอกสารแล้ว ให้อัปโหลดไฟล์ชื่อเดิมได้เลย ระบบจะบันทึกเป็นรอบใหม่ _R1, _R2 … ให้เอง ไม่ต้องเปลี่ยนชื่อไฟล์ และไฟล์เดิมกับลายเซ็นเดิมไม่ถูกแตะ
  • ถ้าไฟล์ที่อัปเหมือนฉบับล่าสุดทุกอย่าง ระบบจะแจ้งว่า "เหมือนกับฉบับล่าสุดอยู่แล้ว" และไม่สร้างรอบใหม่
  • ระบบบันทึกทุกการอัปโหลด: ชื่อผู้อัป แผนก เวลา และชื่อไฟล์
  • ลบไฟล์ได้เฉพาะไฟล์ที่ยังไม่มีใครเซ็น ไฟล์ที่ลบถูกย้ายไปเก็บสำรอง กู้คืนได้
ห้ามเปลี่ยนชื่อ ย้าย หรือลบไฟล์ในไฟล์แชร์ด้วยมือ ลายเซ็นผูกกับชื่อและที่เก็บไฟล์

10ทำงานพร้อมกันหลายคน

หน้าเอกสารอัปเดตสถานะเองทุกประมาณ 10 วินาที เมื่อมีคนอื่นเซ็นหรืออัปโหลด คุณจะเห็นการเปลี่ยนแปลงโดยไม่ต้องรีเฟรช

  • กำลังเซ็นโดย … = มีคนกำลังเซ็นไฟล์นี้ ปุ่มเซ็นและช่องติ๊กของไฟล์นั้นถูกปิดชั่วคราว (ไม่เกิน 10 นาที)
  • เอกสารนี้ถูกอัปเดตโดยผู้อื่น = มีคนเพิ่งเซ็นเอกสารที่คุณเปิดอยู่ กด โหลดใหม่ ก่อนทำต่อ
  • ถ้าสองคนกดเซ็นขั้นเดียวกันพร้อมกัน ระบบให้ได้แค่คนเดียว อีกคนจะเห็นข้อความ "มีผู้อื่นกำลังเซ็นขั้นนี้อยู่" ลายเซ็นไม่ซ้อนกัน

11อีเมลแจ้งเตือน

อีเมลจากระบบมีหัวเรื่องขึ้นต้นว่า IDF-E-Doc |

หัวเรื่องส่งถึงเมื่อไร
แจ้งเตือนถึงคิวเซ็นเอกสารผู้เซ็นขั้นถัดไปเมื่อเอกสารถึงคิวคุณ
แจ้งการ Reject เอกสารผู้เซ็นขั้นก่อนหน้าเมื่อเอกสารถูก Reject (แนบ PDF)
  • อีเมลอาจมาช้ากว่าการกดปุ่มประมาณ 1 นาที
  • ไม่ได้รับอีเมล ตรวจโฟลเดอร์ Junk ก่อน แล้วแจ้งผู้ดูแลระบบ
  • อีเมลแจ้งให้ทราบเท่านั้น การเซ็นต้องทำบนเว็บ
ระวังอีเมลปลอมที่แนบไฟล์แปลก ๆ หรือขอรหัสผ่าน อีเมลจริงของระบบไม่เคยขอรหัสผ่าน

12หน้า Production

แสดงแผนการผลิตรายวัน ดึงจาก AX อัตโนมัติทุกเช้า 07:00 น. จัดกลุ่มตามวันที่ควบคุมการผลิต

  • ข้อมูลต่อรายการ: รหัสสินค้า เลขใบสั่งผลิต ชื่อสินค้า แบรนด์ วันส่ง จำนวนสั่ง ส่งแล้ว คงเหลือ และมูลค่าคงเหลือ

13คำถามที่พบบ่อย

คำถามคำตอบ
ล็อกอินไม่ได้ตรวจชื่อผู้ใช้และรหัสผ่าน ยังไม่ได้ให้แจ้งผู้ดูแลระบบรีเซ็ต
ไม่เห็นแผนกที่ควรเห็นยังไม่มีสิทธิ์ แจ้งผู้ดูแลระบบ
ปุ่มเซ็นกดไม่ได้ยังไม่ถึงคิว เอกสารถูก Reject มีคนกำลังเซ็นอยู่ หรือไม่มีสิทธิ์ขั้นนั้น ระบบบอกเหตุผล
กรอบช่องเซ็นเป็นสีส้มระบบหาช่องเซ็นอัตโนมัติไม่เจอ ตรวจตำแหน่งก่อนเซ็น ถ้าไม่ตรงแจ้งผู้ดูแลระบบ
เซ็นหลายไฟล์แล้วบางไฟล์ถูกข้ามไฟล์นั้นหาช่องเซ็นไม่เจอ เปิดเซ็นทีละไฟล์
